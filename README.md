# cdrdao for MiSTer Companion

This is the **MiSTer Companion** fork/build of [cdrdao](https://github.com/cdrdao/cdrdao).

It provides the cdrdao binaries used by MiSTer Companion for:

- Linux x64 / ARM64
- macOS Intel / Apple Silicon

Windows uses the official upstream Windows build instead.
